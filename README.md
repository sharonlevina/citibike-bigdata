# 🚲 Citi Bike NYC Big Data Analytics Dashboard

**Platform Analitik Big Data Citi Bike New York City**  
Universitas Bina Nusantara — Final Project Big Data Platform 2026

## 📊 Fitur Dashboard
- **Ikhtisar & Arsitektur**: Medallion Lakehouse Architecture (Bronze-Silver-Gold)
- **Analisis Spark SQL**: Pola Rush Hour, Hari Kerja vs Weekend, Member vs Kasual
- **Machine Learning**: K-Means Clustering (Spark MLlib) + Prediksi Durasi (Random Forest)
- **Graph Analytics**: PageRank Stasiun & Optimasi Rebalancing Armada
- **Peta Spasial**: Visualisasi interaktif jaringan stasiun NYC

## 🛠️ Teknologi
- Apache Spark (PySpark) | Spark MLlib | Spark SQL
- NetworkX | Scikit-Learn | Pandas | NumPy
- Streamlit | Plotly | Pydeck

## 🚀 Menjalankan Secara Lokal
```bash
pip install -r requirements.txt
streamlit run app.py
```
